# 드쥬르 합동 비서실 (PICKLE OFFICE)

네 비서(미니미 · 설탕이 · 소금이 · 후니훈)가 함께 쓰는 사무실 페이지입니다.
빌드 도구 없이 `index.html` + `assets/` 만으로 동작합니다.

## 화면

| 탭 | 내용 |
| --- | --- |
| 🏢 오피스 맵 | 미니어처 사무실 배경 위 네 책상에 캐릭터 배치. 캐릭터를 누르면 역할·상태·요즘 하는 일 |
| 📋 지휘실 | 대기 · 진행중 · 완료 3단 칸반, 비서별 필터, 새 지시 추가 (기본은 브라우저에 저장, 중계 서버를 연결하면 노션과 연동) |
| 👥 비서 현황 | 비서별 역할·담당 업무와 여유/보통/소진 상태 표시 |
| 💬 라운지 | 전원 출석 체크 인사, 공지·메모 (브라우저에 저장) |

## 메모

- 저장은 `localStorage` 에만 됩니다. 서버나 계정으로 전송되지 않습니다.
- 사용량 %는 자동 조회가 안 되어 상태를 손으로 고르는 방식입니다.
- 노션 `📮 업무 지시` 와 같은 내용을 쓰면 네 비서가 함께 확인합니다.
- 캐릭터 PNG와 배경 이미지는 미니어처 사진에서 잘라 배경을 투명하게 정리해 사용했습니다.

## 노션 연결 (선택)

지휘실 위쪽 주소 칸에 중계 서버 주소를 넣고 **연결**을 누르면, 그때부터 지휘실 카드는
노션 `📒 AI 업무 일지` 와 함께 움직입니다.

- 지시 추가 → 노션에 `대기` 행이 생김
- → / ← / ⏸ 버튼 → 노션 `상태` 가 `진행중` / `대기` / `보류` 로 바뀜
- 카드 제목을 누르면 노션 페이지가 열림
- 주소를 비우면 예전처럼 브라우저에만 저장(로컬 모드)되고, 연결이 끊기면 마지막으로 받아 둔 목록을 보여 줍니다

중계 서버는 `office/worker/` 에 있습니다. 배포 방법은 [`worker/README.md`](worker/README.md) 참고.
